# 已开始的会话只改自己的模型

[English](guide.md) | 中文

## 变更

`session/selectModel` 仍会为当前会话记录选择，但只有该会话尚未记录任何回合时，才把这份选择存为部署默认值。已经开始过的对话，切换只影响自身：它自己的路由从下一个步骤起生效，而之后新建的会话仍从先前保存的默认值开始。

在新建、尚未开始的对话里切换模型，仍会设置默认值——那正是表达"以后都这样"的手势。[默认模型](../../../../packages/core/agent-default-model/README.zh.md)服务本身没变，仍然写入调用方交给它保存的值。

依赖"任何会话的选择都会成为默认"的消费者，现在必须通过未开始的会话来表达该意图，或直接写默认值。线上字段、事件、存储的设置项都没变：写入的仍是同一个 `agent-default-model` 设置段，只是写得更少。

## 迁移

1. 提供"切换本对话模型"的客户端入口照常可用；删掉任何声称"切换也会改变新会话默认值"的文案。
2. 通过切换已有会话来钉住部署默认值的工作流，改为切换一个未开始的会话，或直接通过设置段设置默认值。
3. 确认在已记录回合的对话里切换模型不会改动 `agent-default-model`，而在新对话里做同样的切换仍会更新它。
